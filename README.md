# 🤖 3D Printable Robotic Arm

![Robotic Arm](https://media.printables.com/media/prints/1915460/rich_content/a284e866-9f9c-45e3-9550-2785d15d39b7/robotic_arm.png)

## 💡 About the Project

This is a **3D-printable robotic arm** that I designed from scratch using **Autodesk Fusion 360**.

The arm has a rotating base, shoulder, elbow, wrist, and a grabber mechanism. It uses **4 servo motors** to control its different movements.

Honestly, I've always been fascinated by mechanical engineering — especially how different parts fit together, connect, and move. That's what inspired me to build this project.

I designed the links, joints, gears, and base myself. While working on it, I learned a lot about mechanical design, joint mechanisms, gear systems, and how the mechanical side of a robotic arm actually works.

This project was also a great opportunity to improve my Fusion 360 skills and turn my ideas into something physical and functional.

A big thank you to **Hack Club Atlantis** for giving me the opportunity and motivation to build things like this! ❤️

## 🛠️ Assembly Guide

Ready to build your own robotic arm? Follow these steps!

### Step 1: Print the Base

![Base](https://media.printables.com/media/prints/1915460/rich_content/65af09dc-0e5e-4a7e-b473-ce432a95492e/base-12.png)

- 3D-print the base component.
- Find the STL file inside the `printed` folder.
- **File name:** `Base`

### Step 2: Install the First Servo Motor

![Base Servo](https://media.printables.com/media/prints/1915460/rich_content/d5ea89cd-ac5a-476c-b5c6-204f08d9dcc4/base.png)

- Place the servo motor into the designated slot.
- Secure it properly using screws.
- Make sure the motor is firmly attached to the base.

### Step 3: Attach the Main Arm

![Main Arm](https://media.printables.com/media/prints/1915460/rich_content/01d38df1-23c3-40a4-bcf7-6982e955c200/screenshot-300.png)

- 3D-print the main arm component.
- **File name:** `Arm`
- Attach it to the servo motor's rotating horn.
- Secure the connection so the arm can rotate smoothly.

### Step 4: Install the Elbow Servo

![Elbow Servo](https://media.printables.com/media/prints/1915460/rich_content/6e52be98-615d-4139-b32f-5af380b6a675/servo-2.png)

- Place another servo motor into the arm's designated slot.
- Secure it with screws.
- Check that the motor is properly aligned.

### Step 5: Assemble the Wrist Mechanism

![Wrist Assembly](https://media.printables.com/media/prints/1915460/rich_content/e27b6bd4-0ebb-4c5e-8123-fb7a5a807025/screenshot-301.png)

- Print the wrist component.
  - **File name:** `wrist`
- Print 2 helical gears.
  - **File name:** `helical gear`
- Attach one gear to the wrist mechanism and the other to the servo motor.
- Position the wrist inside the designated hole in the arm.

### Step 6: Install the Wrist Servo

![Wrist Servo](https://media.printables.com/media/prints/1915460/rich_content/3f38e657-1a24-490b-b9dc-eda64043ea37/screenshot-304.png)

- Install the third servo motor onto the wrist assembly.
- Secure it properly and check the alignment.

### Step 7: Prepare the Grabber Servo Mount

![Grabber Servo Mount](https://media.printables.com/media/prints/1915460/rich_content/c48cd1df-f9bd-420d-8da0-7aeed4ae9cd8/screenshot-311.png)

- Print the servo-to-motor mounting component.
- **File name:** `servo to motor`
- Attach it to the servo motor using glue.

### Step 8: Print the Grabber Base

![Grabber Base](https://media.printables.com/media/prints/1915460/rich_content/105ac2ff-db88-474e-a7bb-ec16fc6287db/screenshot-312.png)

- 3D-print the grabber base.
- **File name:** `grabber`

This component will hold the gear mechanism and the grabbing fingers.

### Step 9: Assemble the Gear Mechanism

![Grabber Gears](https://media.printables.com/media/prints/1915460/rich_content/646528f7-c78f-4a7a-aece-0f6844658b3c/screenshot-313.png)

Print the following gears:

- 1 × Spur Gear (15 teeth)
- 2 × Spur Gear (30 teeth)

- Place the gears into the designated positions inside the grabber.
- Make sure the gears mesh correctly and can rotate freely.

### Step 10: Attach the Grabber Fingers

![Grabber Fingers](https://media.printables.com/media/prints/1915460/rich_content/d8507ef5-f8a7-44fa-aad1-f1494c9fa673/screenshot-314.png)

- Print 2 grabber supports.
  - **File name:** `2 needed`
- Print the left and right grabber fingers.
- Attach the supports and fingers to the designated holes in the grabber base.
- Check that both fingers are properly aligned.

### Step 11: Final Assembly! 🎉

![Final Robotic Arm](https://media.printables.com/media/prints/1915460/rich_content/e69ebc43-d384-4c5e-81de-72ea8d075e79/screenshot-315.png)

- Apply a small amount of glue to the top of the servo mount.
- Attach the assembled grabber mechanism.
- Check all mechanical connections and make sure everything moves freely.

**And that's it! Your robotic arm is mechanically assembled.**

Now comes the fun part — the electronics and programming are yours! 🚀

## 🔮 Future Improvements

There are still a few things I'd love to improve!

The biggest limitation right now is the grabber mechanism. It doesn't have a dedicated servo motor yet, so its grabbing movement isn't independently controlled.

**My next plan:**
- Add a fifth servo motor to the grabber.
- Make the grabbing fingers open and close independently.
- Improve the mechanical design for smoother movement.
- Work on the electronics and control system.
- Experiment with different ways to control the arm.

I hope to keep improving this project and eventually turn it into a fully functional robotic arm.
